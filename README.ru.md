# Lumière

Локальная видеотека для macOS 26: SwiftUI с Liquid Glass, метаданные с TMDB,
отслеживание просмотренного и позиции остановки. Без сервера — всё остаётся на вашем Маке.

[English version](README.md)

![Главная](docs/screenshots/01-home.png)

## Установка

Одной командой через Homebrew:

```bash
brew install --cask shineexxx/lumiere/lumiere
```

Или скачать образ из [последнего релиза](https://github.com/shineexxx/lumiere/releases/latest)
и перетащить Lumière в «Программы».

Приложение подписано ad-hoc, без учётной записи разработчика. Cask сам снимает карантинную
метку; если ставите из DMG руками и macOS говорит, что не может проверить разработчика —
правый клик по приложению → «Открыть», либо:

```bash
xattr -dr com.apple.quarantine /Applications/Lumiere.app
```

Нужна macOS 26 на Apple Silicon. Дальше приложение обновляет себя само — см. [Обновления](#обновления).

## Что умеет

- **Библиотека из ваших файлов.** Указываете папку; вложенные папки обходятся на любую глубину.
  Из имён файлов достаются название, год, сезон и серия — включая «4 сезон 7 серия» и заголовки
  с видеосайтов вида «Название (фильм, 2016)».
- **Метаданные с TMDB.** Постеры, описания, рейтинги, актёры, названия и кадры серий.
  Совпадение подтверждаете вы — или приложение принимает уверенные само.
- **Один движок воспроизведения.** Всё идёт через VLCKit: MKV, AVI, WMV, MPEG-TS внутри `.mp4`
  и прочее, что AVFoundation открывать отказывается.
- **Отслеживание просмотра.** Позиция помнится по каждому фильму и каждой серии, следующая
  включается сама, отметки переживают удаление файлов. По желанию — синхронизация через iCloud
  или экспорт в файл.
- **Загрузки.** Вставляете ссылку на VK Видео или Rutube — файл ложится в папку библиотеки с
  нормальным именем, а плейлист превращается в сезон, разложенный как `Сериал / Сезон N`.
- **Два поиска.** Один фильтрует раздел библиотеки, второй, в правом верхнем углу, ищет по всему
  TMDB — можно открыть карточку того, чего у вас ещё нет.
- **Русский и английский.** Интерфейс следует языку системы; язык метаданных TMDB настраивается
  отдельно.

## Обновления

Приложение при каждом запуске смотрит [GitHub Releases](https://github.com/shineexxx/lumiere/releases)
и сравнивает тег последнего релиза со своей версией.

- **«Обновлять автоматически»** (Настройки → Обновления, включено по умолчанию): новая версия
  скачивается сама и ждёт. Ставится только по кнопке «Перезапустить и обновить», чтобы обновление
  не оборвало просмотр.
- Тумблер выключен — приложение просто сообщает, что вышла новая версия.
- Проверить руками: меню «Lumière» → «Проверить обновления…».

Подмену делает скрипт, который дожидается выхода приложения, распаковывает новую версию поверх
старой и запускает её заново. Перед установкой проверяется, что в архиве лежит приложение с тем же
идентификатором бандла.

## Сборка из исходников

```bash
Scripts/fetch-vlckit.sh   # VLCKit ~540 МБ, в репозитории его нет
open VideoClient.xcodeproj
```

Собрать и запустить — ⌘R. Или из терминала:

```bash
xcodebuild -project VideoClient.xcodeproj -scheme VideoClient -configuration Debug build
```

Подпись ad-hoc (`Sign to Run Locally`), команда разработчика не нужна.

Выпуск релиза (сборка, установка в /Applications, публикация DMG и ZIP, обновление cask):

```bash
# сначала поднять MARKETING_VERSION в проекте
Scripts/release.sh "что изменилось"
```

## Первый запуск

1. **Настройки → TMDB** — вставьте API-ключ (бесплатный: themoviedb.org → Settings → API).
   Подходит и короткий ключ v3, и длинный токен v4. Хранится в настройках приложения.
2. **⌘O** — добавьте папку с фильмами или сериалами.
3. Приложение просканирует её, разберёт имена файлов и предложит совпадения из TMDB.

## VLC

Воспроизведение целиком на VLCKit 4 — один движок на все контейнеры. AVPlayer остался в коде
запасным путём для сборок без фреймворка.

Фреймворк в репозитории не хранится: 543 МБ, отдельные файлы внутри больше лимита GitHub.
`Scripts/fetch-vlckit.sh` кладёт сборку VLCKit 4.0 с artifacts.videolan.org в
`Frameworks/VLCKit.xcframework`. Без него проект тоже собирается — весь VLC-код закрыт
`#if canImport(VLCKit)` — и приложение возвращается к AVPlayer.

Журнал libVLC пишется в `~/Library/Logs/Lumiere/vlc.log` (предупреждения и ошибки); однажды
именно он помог найти причину падения плеера.

## Загрузки

Для загрузок нужны две утилиты:

```bash
brew install yt-dlp ffmpeg
```

Одиночная ссылка превращается в «Название (Год).mp4», плейлист, отмеченный как сериал, —
в «Сериал / Сезон N / Сериал - S04E07.mp4»: понятно в Finder и без приложения.

## Синхронизация

Отметки о просмотре и позиции синхронизируются через iCloud (`NSUbiquitousKeyValueStore`) —
Настройки → Синхронизация. Синхронизируются только отметки, файлы остаются на этом Маке.
Побеждает более свежая запись, а «просмотрено» никогда не снимается автоматически.

Для iCloud нужна подпись приложения вашей учётной записью разработчика: при ad-hoc подписи
контейнер iCloud не выдаётся. Экспорт и импорт через файл работают всегда — импорт сливает
данные, а не заменяет их.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел | Пауза / продолжить |
| ← → | Перемотка на 10 секунд |
| ↑ ↓ | Перемотка на минуту |
| N / P | Следующая / предыдущая серия |
| F | Весь экран |
| Esc | Выйти из полного экрана или закрыть плеер |
| ⌃F | Найти (по разделу библиотеки или по TMDB — смотря где вы) |
| ⇧⌘F | Поиск по всему TMDB |
| ⌘O | Добавить папку |
| ⌘R | Обновить библиотеку |
| ⇧⌘R | Пересобрать карточки из имён файлов |
| ⌘, | Настройки |

## Как устроено

```
VideoClient/
  App/        точка входа, LibraryCoordinator (сканирование + метаданные)
  Models/     MediaEntry, EpisodeEntry, VideoFileRef, WatchState
  Library/    доступ к папкам, сканер, парсер имён, встроенная модель
  Store/      LibraryStore — @Observable, JSON в Application Support
  TMDB/       клиент, DTO, матчер, рекомендации, кэш постеров
  Player/     протокол PlayerEngine, движки VLC и AVPlayer, сессия воспроизведения
  Downloads/  очередь yt-dlp и работа с процессами
  Support/    обновлятор, хранение ключа, миграции
  UI/         сайдбар, сетка, карточка, лист подтверждения, настройки
  Resources/  каталог строк (ru + en), иконка
```

Данные лежат в `~/Library/Application Support/Lumiere/library.json`,
постеры — в `~/Library/Caches/Lumiere/Images`.

Правила просмотра: позиция пишется раз в секунду, файл считается досмотренным на **92%**
длительности, при продолжении отматывается **8 секунд**. Пороги — в `WatchRules`
(`Models/Models.swift`).

## Ограничения

- Файлы мельче 50 МБ пропускаются (`LibraryScanner.minimumFileSize`), чтобы в библиотеку
  не попадали сэмплы и трейлеры.
- Внешние субтитры (.srt/.ass рядом с файлом) не подключаются; встроенные в контейнер дорожки —
  подключаются.
- Библиотека хранится в одном JSON. Для нескольких тысяч карточек это нормально; для десятков
  тысяч разумнее SwiftData.
